# VELORA BAGS

A premium purse e-commerce website built with React, Vite and React Router.

## Features
- Product catalogue with search, category, price and discount filters, and sorting
- Product details, cart, wishlist and a demo checkout (Cash on Delivery)
- Register and login; login is required only to add to the cart and to check out
- Responsive and accessible design

## Run locally
npm install
npm run dev

## Note
This is a frontend-only demo. Accounts, cart and wishlist are saved in the browser, and no real payments are processed.
